# MoviesHub-MVVM-C

## Architecture
- MVVM + Coordinator

## Tech Stack
- Swift
- SwiftUI
- Combine
- async/await

<img src="/readmeGif2.gif" alt="Project Demo" width="250" height="500" />

A modern iOS Movies &amp; TV Shows app built with SwiftUI using MVVM-C . The app leverages async/await for efficient concurrency, protocol-based dependency injection, and modular layers (Model, View and ViewModel) to ensure scalability, testability, and clean separation of concerns.
